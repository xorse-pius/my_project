# FIFA World Cup 2026 Player Performance Dataset Prediction using Machine Learning

## Project Overview
This project uses Machine Learning to predict the number of goals scored by football players based on various player attributes from a FIFA dataset.

We applied a Decision Tree Regressor to predict the goals column.

1. Download the dataset from Kaggle.

2. Place the CSV file in the project directory.

3. Open the Jupyter Notebook.

4. Execute each notebook cell sequentially.

5. Review the predictions and evaluation metrics generated by the model.

## Results

The trained Decision Tree Regressor successfully predicts player goals using the available performance features. Model performance is assessed using MAE, MSE, and R² Score, providing insight into prediction accuracy.
